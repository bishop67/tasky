## Added

- The pomodoro holds several tasks. **Add task…** picks an existing task or creates a new one.
  - The top task is the one you're on; finished sessions count on it.
  - Tick a task done and it leaves the list; the next one moves up.
  - Finish the last one before time's up and the timer stops.
  - Hover a task for × to remove it, or use **Clear all**.
- The timer button on a task elsewhere puts it at the top of the list without dropping the others.

## Changed

- With a day picked in the side panel, **Show all** goes back to every task (it was an ×).
